# Game Settings Menu Checklist

The settings players commonly expect, grouped the way most games organize their menus. Items marked **★** are ones players notice (and complain about) when they're missing.

## Display / Video
- **★ Window mode**: fullscreen, borderless windowed, windowed
- **★ Resolution**
- Monitor selection (multi-monitor setups)
- **★ V-Sync** on/off
- **★ Frame rate cap**, including unlimited plus common values like 30/60/120/144/165/240
- Refresh rate
- Render scale / resolution scale
- **★ Field of view (FOV)**, essential for first-person games
- **★ Brightness / gamma**, usually with a calibration image
- HDR toggle with peak brightness and paper-white sliders
- Aspect ratio / ultrawide support
- UI / HUD scale
- Safe zone adjustment (console/TV)

## Graphics Quality
- **★ Overall quality preset**: Low, Medium, High, Ultra, Custom
- Texture quality
- Shadow quality
- Anti-aliasing (TAA, FXAA, MSAA, or off)
- **★ Upscaling**: DLSS, FSR, XeSS, with quality modes
- Frame generation
- Ambient occlusion
- Reflections / screen-space reflections
- Ray tracing options, if supported
- Draw distance / level of detail (LOD)
- Foliage / vegetation density -- Upper Range of Branches
- Particle / effects quality
- Post-processing quality
- Volumetric fog / lighting
- Anisotropic filtering
- **★ Motion blur** on/off (many players turn it off immediately)
- **★ Depth of field**, chromatic aberration, film grain, lens flare, vignette (each as its own toggle)
- Performance overlay / FPS counter
- Graphics API selection (DX11/DX12/Vulkan), on PC

## Audio
- **★ Master volume**
- **★ Separate sliders** for music, sound effects, dialogue/voice, ambient, and UI
- Speaker setup: stereo, headphones, surround
- Dynamic range / "night mode"
- Mute when the game window is unfocused
- Subtitle and voice language (can also live under Language)

## Controls
- **★ Full key rebinding** for keyboard and mouse
- **★ Controller button remapping**
- **★ Mouse sensitivity**, plus separate aim/ADS sensitivity if relevant
- **★ Invert Y-axis** (and X-axis)
- Controller sensitivity (horizontal and vertical separately)
- Stick dead zones
- Aim assist and its strength (controller)
- Vibration / haptics on/off and intensity
- Adaptive triggers (PS5)
- Toggle vs. hold for sprint, crouch, aim
- Raw mouse input / mouse acceleration
- Controller glyph style (Xbox / PlayStation / Switch prompts)
- Reset to defaults

## Gameplay
- **★ Difficulty**, ideally changeable mid-game
- Camera options: shake, distance, auto-centering
- Tutorial / hint toggles
- Auto-save frequency
- Text speed
- Streamer mode (hides names and copyrighted music)

## Accessibility
- **★ Subtitles** on/off, with size, background opacity, and speaker names
- Closed captions for sound effects
- **★ Colorblind modes**: Change color differences to patterns
- Text size / UI scale
- High-contrast mode
- Reduce screen shake and flashing effects (photosensitivity)
- Screen reader / menu narration
- Game speed / slow-mode options
- Motion sickness options: Cinematic Mode rotation speed

## Language
- Interface language
- Voice-over language, set separately from subtitles
- Subtitle language


## General / Other
- **★ Apply / Revert / Reset to defaults** on every tab
- **★ Settings preview** before confirming changes, with a "keep these settings?" timeout for display changes
- Cloud sync of settings
- Credits
- Privacy policy / data collection opt-out
- Telemetry toggle

## Design Notes
- Players strongly expect settings to be reachable from the **pause menu**, not just the main menu.
- Give each option a short **description** of what it does and how much it affects performance. That matters almost as much as the options themselves.
